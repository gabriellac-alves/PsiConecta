# PsiConecta

Protótipo de uma plataforma web de apoio psicológico voluntário online, desenvolvido como parte da Atividade Extensionista II do curso de Análise e Desenvolvimento de Sistemas.

## Sobre o projeto

O PsiConecta foi desenvolvido com o objetivo de facilitar a conexão entre pessoas que buscam acolhimento psicológico e profissionais de saúde mental interessados em prestar atendimento voluntário.

O projeto apresenta uma interface web simples e responsiva, permitindo demonstrar as principais funcionalidades propostas para a plataforma.

## Funcionalidades

- Solicitação de acolhimento psicológico;
- Cadastro de profissionais voluntários;
- Visualização de profissionais e horários disponíveis;
- Simulação de agendamento de sessão;
- Modo de alto contraste;
- Interface responsiva para diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

- `index.html` — estrutura principal da plataforma;
- `style.css` — estilização, responsividade e modo de alto contraste;
- `script.js` — interações e funcionalidades do protótipo.

## Acessibilidade

O PsiConecta possui um recurso de alto contraste que modifica as cores da interface para oferecer uma alternativa de visualização com maior contraste.

## Demonstração

O protótipo permite demonstrar o fluxo de solicitação de acolhimento, cadastro de profissionais voluntários e simulação de agendamento.

> Este projeto possui caráter acadêmico e consiste em um protótipo. Os dados informados nos formulários não são armazenados em banco de dados e os atendimentos apresentados são demonstrativos.
