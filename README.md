# PsiConecta 🧠💬

> **Plataforma Web de Apoio Psicológico Voluntário Online**  
> Projeto desenvolvido como Trabalho Final da disciplina **Atividade Extensionista II: Tecnologia Aplicada à Inclusão Digital – Projeto** no curso de **CST em Análise e Desenvolvimento de Sistemas** 

---

## 📌 Sobre o Projeto

O **PsiConecta** é uma iniciativa de extensão universitária criada com o objetivo de conectar cidadãos em situação de vulnerabilidade emocional na comunidade de **Fazenda Rio Grande (PR)** a profissionais da saúde mental (psicólogos e terapeutas) dispostos a realizar atendimentos voluntários de forma ética, gratuita e confidencial.

Focado na **inclusão digital** e na democratização do acesso à saúde mental, o projeto disponibiliza uma interface web simples, intuitiva e acessível para facilitar o acolhimento psicológico preliminar e o cadastro de voluntários.

---

## 🎯 Objetivos de Desenvolvimento Sustentável (ODS)

Este projeto está diretamente alinhado com a Agenda 2030 da Organização das Nações Unidas (ONU), atendendo aos seguintes objetivos globais:

*   **ODS 3 — Saúde e Bem-Estar:** Oferecendo suporte e promoção da saúde mental e do bem-estar social para comunidades carentes.
*   **ODS 10 — Redução das Desigualdades:** Democratizando o acesso à terapia e reduzindo disparidades sociais e financeiras no acolhimento emocional.
*   **ODS 17 — Parcerias e Meios de Implementação:** Unindo a academia, profissionais voluntários e instituições de Fazenda Rio Grande (PR) em prol de um impacto social tangível.

---

## ⚙️ Funcionalidades Principais

*   **Módulo de Acolhimento:** Um modal interativo e amigável que orienta o usuário sobre como solicitar acolhimento psicológico de forma confidencial.
*   **Cadastro Demonstrativo de Voluntários:** Formulário de captação de psicólogos com validações estruturadas (incluindo o campo indispensável para inserção do registro profissional - CRP).
*   **Interface Demonstrativa de Agendamento:** Fluxo visual simulado para seleção de horários de atendimento com os profissionais cadastrados.
*   **Acessibilidade Digital (Alto Contraste):** Botão nativo que altera dinamicamente a folha de estilo (CSS) da página para uma paleta de cores de alta legibilidade (Fundo `#1A1A1A` e Textos `#E0E0E0`), atendendo aos princípios do Desenho Universal para pessoas com baixa visão ou restrições visuais.

---

## 🛠️ Tecnologias Utilizadas

A plataforma foi desenvolvida utilizando exclusivamente tecnologias web nativas (frontend), garantindo leveza, rapidez de carregamento e compatibilidade com múltiplos dispositivos (responsividade):

*   **HTML5:** Estruturação semântica de todo o conteúdo.
*   **CSS3:** Estilização visual, paleta de cores acessível (Alto Contraste) e layout responsivo.
*   **JavaScript (ES6):** Manipulação dinâmica do DOM, lógica de abertura/fechamento de modais, validação dos formulários e ativação do modo de acessibilidade.

## 🚀 Como Executar o Projeto Localmente

Por se tratar de uma aplicação puramente frontend hospedada no **GitHub Pages**, você pode rodá-la localmente de forma simples:

1. Clone este repositório em sua máquina:
   ```bash
   git clone https://github.com/[seu-usuario]/psiconecta.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd psiconecta
   ```
3. Abra o arquivo `index.html` em qualquer navegador de sua preferência (Chrome, Firefox, Edge, etc.) ou utilize uma extensão como a *Live Server* no VS Code para rodar um servidor de desenvolvimento local.
